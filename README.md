# ClearAhead

ClearAhead is an assistive device prototype that uses sensors and a camera to detect low-hanging obstacles and warn people who are blind or have low vision.

## Project layout

- `src/` holds device code.
- `docs/` holds hardware notes, wiring diagrams, and test observations.

## Getting started

Open this folder in VS Code using **File > Open Folder**. Add the available hardware to [the hardware inventory](docs/hardware.md). The hardware will determine the programming language and development tools.

The first prototype focuses on detecting overhead obstacles and delivering a timely alert. Evaluate it as a supplement to existing mobility aids during controlled testing.
